# 任務規格

## 1. 目標與閱讀對象
- 目標：待填
- 對象：待填

## 2. 交付成果
- 成果種類、檔名及預計位置：待填

## 3. 已確認的內容與設計
- 必須包含的內容：待填
- 區塊順序、風格及功能：待填

## 4. 素材與專案位置
- 專案根目錄（由本人與 Agent 核對）：待填
- 文字、圖片及其他素材的相對路徑：待填

## 5. 修改範圍與限制
- 要修改：待填
- 要保留：待填
- 其他限制：待填

## 6. 驗收清單
- [ ] 內容、日期與數字正確
- [ ] 交付成果可開啟
- [ ] 圖片與連結正常（適用時）
- [ ] 手機畫面可閱讀（網站適用）
- [ ] 已符合上述內容與設計要求
- [ ] 已列出未完成事項與成果位置

## 7. 待確認事項
- 待填；沒有則填「無」

## 8. 給 Agent 的執行要求
先核對工作資料夾並讀取本規格，檢查素材及阻礙實作的缺漏。
資料足夠時依規格製作，只修改相關檔案，完成後回報驗收結果。
未知資料標示待確認，不要捏造。
