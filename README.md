# AI 新員工報到｜同梯 AI Agent 實作教室
繁體中文靜態教學網站。直接編輯 index.html、style.css、app.js 後發布；不需要安裝套件。

## 本機預覽
在此目錄執行 `python3 -m http.server 8080`，開啟 http://localhost:8080。

## 編輯入口
- index.html：課程內容、工具連結、問卷入口。實際學員問卷網址尚待老師提供。
- style.css：配色、手機版與版面。
- app.js：指令複製、系統選擇、瀏覽器本機進度。
- downloads：練習素材、指令小抄與問卷 Apps Script（需本人登入執行）。
- slides：既有漫畫簡報，沿用原始內容。
- assets：使用者既有海報及影片。
