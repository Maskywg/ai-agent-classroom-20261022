BEFORE YOUR FIRST TASK

任務開始前，先選對工作資料夾。

就像給新員工一張專屬辦公桌：材料放這裡，成果也存這裡。每個作品各用一個專案資料夾，之後找檔案、保存版本都更清楚。

① 在電腦上建立專案資料夾

  1. Mac：在 Finder 選擇桌面或文件等方便找到的位置，按右鍵 →「新增檔案夾」，例如命名為「AI練習」。
  2. Windows：在檔案總管選擇桌面或文件等位置，按右鍵 →「新增」→「資料夾」，例如命名為「AI練習」。
  3. 進入「AI練習」，再建立自己的作品資料夾，例如「我的旅遊網頁」。同一堂課用這個作品資料夾持續操作。
  4. 把本次會用到的文字、照片放進去；第一次可先放一份練習文字即可。
專案範例
📁 AI練習
　└─ 📁 我的旅遊網頁 ← 在 Agent 選這一層
　　　├─ 📄 旅遊素材.txt
　　　├─ 📁 照片
　　　└─ 🌐 index.html ← 製作後的成品

第一次選專用練習資料夾即可，不要直接把整個桌面、整個雲端硬碟或磁碟根目錄當成專案。若教材在雲端，先確認需要的檔案已能在本機讀取。

② 在 Agent 選擇這個資料夾

  1. 開啟已登入的 Agent，進入可操作本機檔案的工作介面。
  2. 建立任務或專案時，尋找「選擇資料夾」「開啟資料夾」「新增專案」或工作區相關入口；名稱依工具及版本不同。
  3. 選取剛建立的「我的旅遊網頁」資料夾，確認開啟；若出現信任或存取要求，先確認顯示的路徑正確。
  4. 查看目前專案名稱或檔案清單，再貼上下方確認指令。

若選不到本機資料夾，先確認目前是否在本機 Agent 工作環境；一般網頁聊天上傳附件，與指定本機專案是不同操作。

③ 每次開始、切換任務，都確認位置

同一作品可繼續使用原資料夾；換新作品時，先建立新資料夾，再切換或建立對應專案。新開對話後也確認一次，避免沿用上一個作品的位置。

開始任務前，請確認這次使用的工作資料夾。
1. 回報目前專案根目錄的完整路徑。
2. 列出第一層檔案與資料夾，先不要修改。
3. 告訴我文字、圖片與成品預計放在哪裡。
4. 若目前位置不是我指定的專案，請先引導我切換，不要在錯誤位置建立檔案。
5. 若無法讀取，請說明需要我選擇資料夾或授權的步驟。
我確認位置正確後，再開始製作。
驗收：你和 AI 指的是同一張辦公桌嗎？

核對 Agent 回報的完整路徑，確認它能列出你剛放入的文字檔。作品完成後，回到同一資料夾找成品，依 Agent 說明開啟預覽。

只貼檔案路徑，不一定會切換目前專案；請明確確認工作資料夾。若顯示「找不到檔案」或「沒有權限」，先檢查位置與授權，再繼續。

KNOW YOUR AI TEAMMATE

認識員工能力，也看懂工作額度。

安裝、登入後先做這一站。以下用員工比喻幫助理解；實際配額依帳號、方案、模型與官方介面為準。查核：2026/10/23。

模型＝員工的專長與能力

軟體是辦公室，模型是裡面的員工。同一套軟體可能讓你選不同模型。改字、整理資料可先用快速／輕量模型；複雜規劃、除錯再選推理能力較強的模型。先做小任務驗收，沒有一位員工適合所有工作。

推理強度＝這次思考的投入

同一位員工也能快速處理，或花更多心力研究。High／Max、Thinking 等設定是思考投入，不是「保證正確」；通常會影響等待與消耗。初學先用預設或一般強度，遇到難題再提高。

Token＝讀寫資料的計量單位

可想成員工處理的「資料小格」，但不是一字一格，也不是一分鐘。指令、讀進來的檔案、對話紀錄、工具回傳、回答，以及部分模型的推理都可能影響消耗。只說一句「幫我做網站」，背後也可能讀寫很多內容。

上下文＝辦公桌的容量

桌上能同時攤開的資料有限；context 使用百分比表示這一段對話的資料空間。接近滿載時可先保存成果、整理摘要，再延續或另開任務。桌子整理乾淨，不代表帳號使用額度恢復。

使用限制＝工作量配額與排班

可比喻「這一班／這一週還能接多少工作」。較難的任務可能較耗額度；五小時視窗是配額計算週期，並非保證五小時連續工作。各方案可能有短期、每週或模型別限制，請看實際重設時間。

Credits／API＝另一份加班預算

訂閱額度、額外 credits 與 API 用量要分開看。購買月費不等於 API 免費；切換模型也不保證有新的獨立配額。需要加購時，先看計費方式與金額；課堂先使用既有額度。

看懂百分比：Used 80% 是已用八成；Remaining 80% 是剩八成。Context 80% 則是桌面已放八成資料，不能拿來推算月費剩多少。平台未顯示精確 Token 時，不請 AI 猜出一個數字；以用量頁為準。

Claude Code：到哪裡查？

  1. 看方案額度：瀏覽器登入同一 Claude 帳號 → 個人選單 → Settings（設定）→ Usage（使用量）。也可直接開啟下方官方用量頁，查看方案限制、重設時間與額外用量設定。
  2. 命令列版觀測：在正在執行的 Claude Code 提示列輸入 /usage，看可用的方案用量與當次統計；/context 看上下文占用。不要貼到一般作業系統終端機，也不要假設 Claude 一般聊天視窗支援相同指令。
  3. 選模型：Claude Code CLI 輸入 /model 開啟選單；桌面版 Code 工作區則找目前模型名稱／模型選單，選帳號實際提供的模型。先用一般模型處理小修改，較難任務再選深度推理。
  4. 若用 API key：請到 Claude Console 的 Usage／帳務看實際用量；部分版本支援 /cost，新版也會在 /usage 顯示 session 統計。訂閱者看到的估算成本，不等於另外收取那筆費用。

看到限制時：先確認是哪個視窗或模型的額度與重設時間；整理好檔案，等恢復或依帳號可用選項調整。取不到用量與用量耗盡是兩件事。

Claude 用量頁 ↗官方用量說明 ↗官方模型設定 ↗

ChatGPT／Codex：到哪裡查？

  1. 看帳號額度：登入使用 Codex 的同一 ChatGPT 帳號，開啟官方 Codex usage dashboard（下方直達連結），查看當前限制、重設時間及 credits。桌面版也可找個人選單／Settings 的用量入口；各版位置可能不同。
  2. 看 Token 活動：支援的桌面版到 Settings → Profile，可看 token activity 等統計；這是活動量，不是剩餘配額。CLI 輸入 /status 看目前狀態；用 /statusline 選擇 context、Token 計數與 rate limits 等頁腳項目，依版本提供內容為準。
  3. 選模型與思考強度：在 Codex 的模型選單點目前模型名稱，再調整可用推理強度；CLI 用 /model。快速／輕量模型先做改字整理，較強模型處理規劃除錯，無須所有工作都用最高強度。
  4. 若用 API key：到 OpenAI Platform → Usage 查 API Token／費用；這與 ChatGPT 訂閱用量分開。一般 ChatGPT 聊天的模型選擇，也不要直接當成 Codex 的設定。

看到限制時：先看 dashboard 指的是哪一項 allowance、何時重設；換模型可能減少之後的消耗，但不能假設會重置已用額度。

Codex 用量頁 ↗API 用量頁 ↗官方用量與配額 ↗模型說明 ↗桌面設定說明 ↗CLI 指令說明 ↗

Antigravity：到哪裡查？

  1. 看目前模型：進入對話，找輸入框下方的 model selector（模型選單）。點開檢查可選模型；可用清單受方案影響，不把教材中的某個型號視為人人都有。
  2. 看工作額度：在模型選單找 View Usage（若版本提供），或到 Settings（設定）查看各模型 baseline quota。看清楚 Remaining、重設時間，以及是否分不同模型／模型群組。
  3. 命令列版：Antigravity CLI 輸入 /usage（別名 /quota）開啟配額面板；輸入 /context 看對話 Token 與上下文分類。這些是 CLI 操作，不保證桌面／IDE 同名指令可用。桌面若沒有精確 Token 累計，就先用官方額度頁觀測。
  4. 看額外消費設定：在 Settings 檢查 AI Credit Overages 等選項（若方案提供）；Never 表示不自動動用額外 credits，Always 可能在基礎額度耗盡後使用 credits。實際授權與費用請讀清楚再設定。

看到限制時：依畫面等待相應額度恢復，或選擇仍可用的模型。Antigravity 裡使用 Claude 模型，額度依 Antigravity 方案，不會因你另有 Claude 訂閱就自動合併。

現場練習：找到自己的員工資料卡

請每位學員找到：① 目前模型與思考設定　② 帳號用量頁與重設時間　③ Token／上下文資訊（有提供才記）。不用公布帳密或購買額度。若只看到百分比，先確認它寫「已用」還是「剩餘」。

找不到時：告訴老師你用的軟體、桌面／CLI 版本、登入方式，以及遮住個資後的畫面；不要只問 AI「我還剩多少 Token」。

TRAIN YOUR AI TEAMMATE

員工之訓練篇：把好方法變成 Skill。

完成第一個作品後再練習。你已經找到的好流程，可以整理成下次繼續使用的教材。

模型像員工的能力，Skill 像公司的工作手冊。你不用每次從頭交代排版、步驟與驗收標準；讓 Agent 在合適任務中讀取同一份教材，工作就更容易保持一致。這裡的「訓練」是工作流程教學，不會重新訓練模型參數，也不保證永遠不出錯。

一份 Skill，裝什麼？

通常是一個資料夾，核心是 SKILL.md，寫清楚名稱、適用時機、工作步驟與完成標準。依需要附上範本、參考資料或腳本。初學先用純文字規範，不必寫程式。

activity-webpage/
├─ SKILL.md　← 工作教材
├─ references/　← 參考資料（可選）
└─ assets/　← 版型、素材（可選）

哪些事適合整理成 Skill？

會反覆執行、標準相近的工作，例如「活動介紹網頁」「旅遊行程整理」「照片與圖說排版」。只有這一次的日期、照片和地點，放在當次任務素材；不要把每次不同的資料寫死在教材裡。

例：固定繁體中文、行動版、活動資訊區與驗收方式；每次再提供新的活動資料。

Skill、指令與連接器怎麼分？

當次指令：今天請員工做什麼。
Skill：這類工作應依哪套方法做。
Rules／AGENTS.md 等：工作區共同規矩，作用範圍依工具。
MCP／連接器：員工能使用的外部工具與服務；安裝 Skill 不等於完成帳號連接。

裝好，不等於學會做好。

請 Agent 說明讀到哪份教材、準備如何套用，再用小任務試做。檢查結果，將修正寫回 Skill。Skill 也會占用上下文與工作用量；它不能增加模型能力上限、繞過權限或恢復額度。

採用第三方教材前，先看來源與內容，特別是腳本、網路傳送、帳號或費用需求。

三套軟體：教材放哪裡、怎麼用？

以下是本機專案的基本位置，路徑從「你目前開啟的作品資料夾」開始。可先請 Agent 確認工具與版本，再協助建立；不要把任意一份 SKILL.md 貼進聊天，就當成已完成安裝。桌面、CLI、雲端與外掛的載入方式可能不同。

WHEN YOU GET STUCK

卡關時，讓 AI 看見你遇到的問題。

把問題圈出來，把檔案位置說清楚。附上「正在做什麼、預期結果、實際情況」，AI 才容易找到下一步。

① 截圖標示：把卡住的地方圈出來

  1. 保留問題附近的按鈕與完整錯誤訊息，擷取畫面。
  2. 用截圖工具的標示功能，加上紅框、圈圈或箭頭，指出要處理的位置。
  3. 把圖片拖入對話欄，或用附件按鈕上傳，再補一句具體說明。
  4. 依 Agent 建議逐步操作；若沒有解決，回傳新的畫面與結果。

Mac：按 Shift + Command + 4 選取範圍，點截圖縮圖進入標示。
Windows：按 Windows + Shift + S 選取範圍，開啟截圖通知後用剪取工具的畫筆標示，再儲存或複製貼上。

傳送前遮住密碼、API key 與個人資料。錯誤文字也可以一併複製貼上，方便準確判讀。

我正在做：【例如：發布網頁】

實際發生：【例如：出現錯誤訊息】

若畫面資訊不夠，請說明需要補拍哪個範圍，不要猜測看不到的內容。

② 貼檔案路徑：告訴 AI 材料在哪裡

路徑就像檔案的地址。先在檔案管理工具選取檔案，再複製完整路徑，貼到本機 Agent 的對話欄。

Mac / Finder

  1. 開啟 Finder，找到並點選檔案或資料夾。
  2. 按 Option + Command + C 複製路徑。
  3. 回到 Agent，按 Command + V 貼上。

也可按住 Option 再對檔案按右鍵，選「拷貝⋯作為路徑名稱」。快捷鍵要在 Finder 選取項目時使用。

/Users/你的名稱/Desktop/AI練習/活動素材.txt

Windows / 檔案總管

  1. 按 Windows + E 開啟檔案總管，找到檔案或資料夾。
  2. Windows 11：對項目按右鍵 → 選「複製為路徑」（Copy as path）。
  3. Windows 10：按住 Shift 再對項目按右鍵 → 選「複製為路徑」。
  4. 回到 Agent，按 Ctrl + V 貼上。路徑外圍的雙引號可保留。

若找不到選項，可嘗試按住 Shift 再按右鍵，或展開「顯示其他選項」。請選完整檔案路徑，而非只複製所在資料夾的網址列。

"C:\Users\你的名稱\Desktop\AI練習\活動素材.txt"

貼上路徑不等於上傳檔案或自動授權。本機 Agent 需要能存取該位置；一般網頁聊天或雲端 Agent 無法只靠你的電腦路徑讀檔，請改用附件上傳。雲端同步檔案也要先確認已下載到本機。

請讀取以下本機檔案：
【在此貼上完整檔案路徑】
我的目標是：【例如：依這份文字製作網頁】
請先確認檔案是否存在、是否能讀取，簡述內容，先不要修改。
若無法存取，請告訴我需要開啟哪個資料夾、提供附件或完成哪些授權。
