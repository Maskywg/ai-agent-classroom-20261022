01第一次見面｜確認辦公桌
你是我的 AI 工作助理，我沒有程式基礎。請用繁體中文回答。
請確認目前開啟的工作資料夾，列出裡面的檔案，先不要修改。
02工作規矩｜先說清楚
我是初學者，請用繁體中文與我溝通。
先確認工作資料夾，簡短說明計畫，只修改任務需要的檔案。
安裝工具、刪除檔案、上傳資料或公開發布前，先向我確認。
需要登入或授權時，說明操作步驟。發生錯誤先找原因。
完成後告訴我成果位置、檢查結果與需要我驗收的地方。
03工具健檢｜檢查再安裝
我要製作簡單網頁、使用 GitHub 保存作品，也想安裝 Google 雲端硬碟電腦版。
請先檢查作業系統、Git 與 GitHub CLI 的安裝及登入狀態。
列出缺少的必要工具與用途，先不要安裝，不需要的工具不要加入。
04安裝助手｜逐項完成
請協助安裝剛才確認需要的工具，逐項進行，使用官方來源。
每完成一項就確認安裝成功。
需要我輸入電腦密碼、登入或授權時，停下來說明下一步。
完成後列出已完成與仍需要我操作的項目。
05第一個作品｜同學會網頁
請讀取目前資料夾的文字與照片，製作「同學會活動介紹」一頁式網頁。
對象：同學。內容：活動介紹、時間地點、交通方式。
風格：有圖片、大字、清楚活潑，手機也方便閱讀。
使用簡單 HTML 與 CSS，缺少資訊標示「待補」，不要編造。
存放在目前資料夾，告訴我如何開啟預覽，並檢查連結及手機版。
06驗收修改｜說具體一點
請把標題與內文字體放大，背景改成米白色。
保留文字與內容順序，只調整視覺樣式。
檢查手機畫面，確認沒有文字被切掉或橫向捲動。
列出修改的檔案與檢查結果。
07GitHub｜保存與分享
請協助把這個網頁專案保存到我的 GitHub。
先確認 Git、GitHub CLI 與登入狀態，檢查預計上傳的檔案，排除密碼與私人資料。
說明公開與私人差異，讓我選擇後再建立獨立儲存庫。
若我同意公開，協助啟用 GitHub Pages，驗證網址可開啟。
需要登入或授權時請引導我操作，完成後給我 repo 與網站連結。
08Drive｜整理素材
請協助設定 Google 雲端硬碟電腦版。
我要建立「AI課程素材」資料夾，存放文字與照片。
先說明串流與鏡像／離線副本的差異，讓我選擇後再設定。
先不要同步整個桌面或文件資料夾。
請確認練習檔案已下載到本機、可讀取，並說明同步刪除的影響。

05 / CONNECT THE DOTS

讓作品有家，讓素材有序。

先完成基本流程，需要時再接外部工具。帳號、電腦軟體、外掛／MCP 是不同層次。

⑂

GitHub：作品的版本倉庫

Git 是本機版本管理；GitHub 是雲端儲存庫；GitHub CLI 是協助登入及操作的工具。裝好 CLI 不等於已授權 Agent 的外掛。

  1. 建立 GitHub 帳號，請 Agent 檢查 Git 與 CLI。
  2. 依引導登入，將專案保存為第一個版本。
  3. 想分享靜態網頁：到 repo 的 Settings → Pages，選擇分支與資料夾後儲存。
  4. 等待部署成功，開啟網址實際驗收。

公開 repo 與公開網頁會讓別人看到內容。上傳前移除帳密、API key 與個人資料。Pages 適合靜態網站。

△

Google Drive：素材文件櫃

安裝雲端硬碟電腦版，登入後在 Finder 或檔案總管找到 Drive，建立「AI課程素材」。先用單一資料夾練習。

  1. 從官方下載 Windows 或 Mac 安裝檔。
  2. 依安裝程式引導完成，登入 Google 帳號。
  3. 串流節省本機空間；鏡像／離線副本保留檔案在電腦，會使用硬碟空間。
  4. 確認需要的材料可離線讀取，再交給 Agent。

同步會傳遞變更，包含刪除；版本保存仍交給 GitHub。桌面同步與 Agent 的 Google Drive 連接器需分別設定。
