1. 今天，我們要完成一個能分享的網頁。你不需要先會寫程式。這三個小時，我們會從準備工具開始，一起交代任務、製作作品、檢查修改，再把作品保存並發布。你負責決定目標和驗收，A、I 協助動手執行。

2. 今天分成六站。第一站，安裝 Agent，選好工作資料夾，四十分鐘。第二站，準備 Git 與 GitHub 工具，三十分鐘。第三站，交代任務、做網頁，五十分鐘。第四站，驗收修改，三十分鐘。第五站，保存發布，二十分鐘。最後十分鐘，整理 Google Drive 素材。時間是建議安排，會依現場進度調整。

3. 第一站，讓你的 A、I 員工報到。Claude Code、Codex 或 Antigravity，第一堂先選一套。我們完成安裝、登入，並進入能操作本機檔案的工作介面。只有打開聊天視窗還不算完成；要能讓 Agent 讀出練習資料夾裡的檔案。

4. 這一步最重要：先給 Agent 一張專屬辦公桌。在電腦建立 A、I 練習資料夾，裡面再建立我的旅遊網頁。把文字和照片放進作品資料夾，並在 Agent 選擇這一層。先確認目前位置，再開始任務。不要直接把整個桌面或整個雲端硬碟當成專案。

5. 模型就像員工的能力與專長。同一套軟體，可以選不同模型。改文字、整理資料，先用快速或輕量模型；規劃複雜網站、處理難解錯誤，再考慮較強模型。推理強度則像同一位員工，這次要花多少心力思考。強度提高不保證正確，通常也會影響等待與消耗。

6. 使用限制，可以想成員工這一班或這一週，還能接多少工作。但這只是比喻，五小時視窗不是保證連續工作五小時。難題可能消耗較多額度。請看實際用量頁的限制和重設時間。額外 credits 像加班預算，而 API 是另外計量的服務，不能以為付了月費就全部免費。

7. Token 可以想成員工讀寫資料的小格，不是一字一格，也不是一分鐘。指令、檔案、對話和工具回傳，都可能消耗。上下文像辦公桌，表示當次能攤開多少資料。桌面用了八成，不等於帳號配額用了八成。整理對話可以釋放上下文，卻不會重置使用額度。平台沒顯示精確 Token 時，不要請 A、I 猜數字。

8. 使用 Claude Code，先在瀏覽器登入同一 Claude 帳號，進入設定，再開啟 Usage 使用量。命令列版可以輸入斜線 usage 看可用統計，斜線 context 看上下文，斜線 model 選模型。桌面版則找 Code 工作區的模型選單。這些命令不要直接貼到一般聊天視窗。訂閱額度與 API 帳單也要分開看。

9. Codex 請用同一 ChatGPT 帳號開啟官方用量頁，看目前限制和重設時間。命令列輸入斜線 status 看狀態，用斜線 statusline 選擇 Token、上下文和額度等觀測項目。支援的桌面版，也能在設定的 Profile 看 Token 活動。選模型時點目前模型名稱，或在命令列用斜線 model。API 用量另到 OpenAI Platform 查。完整連結都放在課程網站。

10. Antigravity 在對話輸入框下方找模型選單，查看可用模型。用量可從 View Usage，或設定裡的基礎配額查看。命令列版有斜線 usage 或 quota 看配額，斜線 context 看 Token 與上下文。桌面版不一定支援相同指令。注意 Remaining 是剩餘額度，並檢查是否啟用了額外 credits。實際位置與可選模型，依你安裝的版本和方案為準。

11. 第二站，先準備作品保存工具。Git 在電腦上記錄檔案版本，GitHub 在雲端保存專案，GitHub CLI 則協助操作。請已安裝的 Agent 檢查工具，缺少才安裝，登入授權由本人完成。這一站先準備好，等作品驗收後再保存發布。

12. 第三站，開始做作品。可以選旅遊行程、診所介紹，或同學會活動。告訴 Agent，你要給誰看、希望完成什麼，提供文字和照片，說明喜歡的風格，以及要存在哪裡。再請它完成網頁並提供預覽。這一站的成果，是能在瀏覽器打開自己的作品。

13. 第四站，驗收修改。A、I 說完成了，我們還是要親自打開看。先檢查文字、日期和地點，再點圖片、按鈕和連結，最後看看手機畫面。發現問題時，告訴它在哪裡、原本預期什麼、實際看到什麼。附上截圖，完成至少一輪修改。

14. 第五站，保存並發布。把驗收過的作品存進 GitHub，留下第一個版本。如果要分享靜態網頁，再透過 GitHub Pages 發布。等待部署完成後，要實際開啟網址確認。上傳前，也請檢查是否含有帳密或不適合公開的個人資料。

15. 第六站，整理雲端素材。安裝 Google Drive 電腦版，登入並建立課程素材資料夾。認識同步方式，確認需要的文字和照片已經能在本機讀取，再交給 Agent。GitHub 保存作品版本，Drive 整理素材，兩者各有用途。

16. 今天的重點，不是一次學會所有工具，而是走完一個完整流程。開工具，選對資料夾，說清楚任務。打開成果，檢查修改，再保存分享。現在，請打開你的 Agent，確認工作資料夾。我們一起開始第一份任務。
