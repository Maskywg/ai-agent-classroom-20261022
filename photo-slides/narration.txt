1. 今天，我們要完成一個能分享的網頁。你不需要先會寫程式。這三個小時，我們會從準備工具開始，一起交代任務、製作作品、檢查修改，再把作品保存並發布。你負責決定目標和驗收，A、I 協助動手執行。

2. 今天分成六站。第一站，安裝 Agent，選好工作資料夾，四十分鐘。第二站，準備作品保存工具，三十分鐘。第三站，交代任務、做網頁，五十分鐘。第四站，驗收修改，三十分鐘。第五站，保存發布，二十分鐘。最後十分鐘，整理 Google Drive 素材。時間是建議安排，會依現場進度調整。

3. 第一站，讓你的 A、I 員工報到。Claude Code、Codex 或 Antigravity，第一堂先選一套。我們完成安裝、登入，並進入能操作本機檔案的工作介面。只有打開聊天視窗還不算完成；要能讓 Agent 讀出練習資料夾裡的檔案。

4. 這一步最重要：先給 Agent 一張專屬辦公桌。在電腦建立 A、I 練習資料夾，裡面再建立我的旅遊網頁。把文字和照片放進作品資料夾，並在 Agent 選擇這一層。先確認目前位置，再開始任務。不要直接把整個桌面或整個雲端硬碟當成專案。

5. 第二站，先準備作品保存工具。Git 在電腦上記錄檔案版本，GitHub 在雲端保存專案，GitHub CLI 則協助操作。請已安裝的 Agent 檢查工具，缺少才安裝，登入授權由本人完成。這一站先準備好，等作品驗收後再保存發布。

6. 第三站，開始做作品。可以選旅遊行程、診所介紹，或同學會活動。告訴 Agent，你要給誰看、希望完成什麼，提供文字和照片，說明喜歡的風格，以及要存在哪裡。再請它完成網頁並提供預覽。這一站的成果，是能在瀏覽器打開自己的作品。

7. 第四站，驗收修改。A、I 說完成了，我們還是要親自打開看。先檢查文字、日期和地點，再點圖片、按鈕和連結，最後看看手機畫面。發現問題時，告訴它在哪裡、原本預期什麼、實際看到什麼。附上截圖，完成至少一輪修改。

8. 第五站，保存並發布。把驗收過的作品存進 GitHub，留下第一個版本。如果要分享靜態網頁，再透過 GitHub Pages 發布。等待部署完成後，要實際開啟網址確認。上傳前，也請檢查是否含有帳密或不適合公開的個人資料。

9. 第六站，整理雲端素材。安裝 Google Drive 電腦版，登入並建立課程素材資料夾。認識同步方式，確認需要的文字和照片已經能在本機讀取，再交給 Agent。GitHub 保存作品版本，Drive 整理素材，兩者各有用途。

10. 今天的重點，不是一次學會所有工具，而是走完一個完整流程。開工具，選對資料夾，說清楚任務。打開成果，檢查修改，再保存分享。現在，請打開你的 Agent，確認工作資料夾。我們一起開始第一份任務。
